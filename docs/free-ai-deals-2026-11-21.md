## Scope, verification and how to read this

Verified **2026-11-21**, against vendors' own public pages using `curl -L`; Chrome was used for JetBrains' JavaScript-rendered page, OpenRouter's numeric limits, and a Mistral missing-page check. This is a dated snapshot, not a promise that quotas will remain unchanged. No signup, application, purchase, authenticated API request, or personal information entry was performed.

Profile: individual in Vietnam; no company or student status; small/new public GitHub OSS project. Ranking below is practical value for the next month, not nominal dollar value. Recurring free tiers outrank competitive grants and review queues. A **Yes** means worth using/applying under the stated conditions, not that an account or grant has been approved. Application instructions below are for the owner to perform later.

**Counts: 32 candidates: 21 verified offers worth considering (including 2 review-based programs), 7 verified unavailable/blocked candidates, and 4 unverified candidates.** Thus 28 candidates have a verified current disposition; only 21 are recommendations. Country eligibility and unpublished quotas are separately qualified, never inferred from a successful page fetch.

Unless a detail says otherwise, the cited offer page publishes **no enrollment deadline or fixed end date**; a recurring tier is ongoing only while the vendor maintains it. For vendors whose reviewed offer page does not publish a country list, **Vietnam account acceptance is unverified**; absence of a restriction is not proof of worldwide eligibility. Company/student/popularity requirements are not imposed by the cited ordinary individual tiers unless stated. Normal account, age, legal/export and anti-abuse rules still apply. Do not use a VPN or false country to bypass restrictions.

## Per-deal details — verified offers and conditional programs

### 1. GitHub Copilot Free

- **Offer and limits:** [Official plan comparison](https://github.com/features/copilot/plans) verifies 2,000 monthly completions and limited chat/agent usage for $0. Do not reuse older “50 chat requests” figures: a current numeric allowance was not established. [Individual-plan documentation](https://docs.github.com/en/copilot/concepts/billing/individual-plans) confirms the individual free route and says it cannot be used alongside organizational/enterprise Copilot access. Current official pages differ on model-selection details, so no specific free model access is promised here.
- **Eligibility/application:** Individual account, not a startup/student/OSS award. Owner can select **Get started** on the plan page and configure their IDE. Vietnam acceptance not separately verified on an explicit GitHub country list.
- **Deadline/expiry/verdict:** No stated deadline; monthly allowances. **Yes:** useful immediately without proving project popularity.

### 2. CodeRabbit for public repositories

- **Offer:** Pricing-page FAQ says **free reviews forever for public repositories**, with no additional setup beyond installation. No guaranteed free PR count or paid-feature equivalence is stated; review allowances remain subject to the fair-usage policy on the [same official page](https://www.coderabbit.ai/pricing).
- **Eligibility/application:** Sign in using GitHub/GitLab and install on a public repository. No company, student or star threshold stated; Vietnam acceptance unverified. Installation grants repository permissions, so the owner should review them first.
- **Deadline/expiry/verdict:** No application closing date; “forever” is vendor wording, not an immutable contract. **Yes:** focused code-review support for a small public project.

### 3. GitHub Actions for public repositories

- **Offer:** [Billing documentation](https://docs.github.com/en/billing/concepts/product-billing/github-actions) makes standard hosted runner compute free for public repositories; it is not the private-repo minute allowance. Larger runners are billable even for public repos. Artifacts/storage have separate allowances; “free compute” does not mean unlimited retained build output.
- **Eligibility/application:** Enable workflows in the public repository; owner account required, not student/company/popularity verification. Vietnam acceptance not explicitly confirmed.
- **Deadline/expiry/verdict:** Ongoing tier, no announced deadline. **Yes:** best place for the project's existing Python integration tests. Use finite jobs, not permanent hosting or unrelated compute.

### 4. GitHub Codespaces

- **Offer:** [GitHub Free personal accounts](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) receive **120 core-hours + 15 GB-month each month**. The documented 2-core multiplier means 60 actual running hours on that machine size, not 120. Stopped environments still consume storage until deleted.
- **Eligibility/application:** Personal GitHub Free account; enterprise-managed users excluded. Create a codespace from the repository's Code menu later. No company/student/popularity gate; Vietnam acceptance not explicitly confirmed.
- **Deadline/expiry/verdict:** Resets each billing cycle; no published program end. **Yes:** useful isolated development capacity; stop/delete unused environments and avoid authorizing paid overages.
